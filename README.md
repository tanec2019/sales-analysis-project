# Анализ продаж интернет-магазина

## О проекте

Данный проект выполнен в рамках изучения анализа данных на Python. Цель — продемонстрировать навыки работы с данными: загрузка, очистка, анализ с помощью SQL, визуализация и формулировка выводов.

**Инструменты:**
- Python (Pandas, Matplotlib)
- SQL (SQLite)
- DBeaver (отладка SQL-запросов)
- Jupyter Notebook

## Структура проекта
sales-analysis-project/
├── sales.csv # Исходные данные о продажах
├── sales.db # База данных SQLite
├── analysis.ipynb # Jupyter Notebook с анализом
└── README.md # Описание проекта


## Данные

Файл `sales.csv` содержит информацию о продажах за январь-март 2024 года:

| Поле | Описание |
|------|----------|
| date | Дата продажи (YYYY-MM-DD) |
| product | Наименование товара |
| category | Категория товара |
| price | Цена за единицу (руб.) |
| quantity | Количество |

## Задачи проекта

1. Загрузить данные из CSV в базу данных SQLite
2. Выполнить аналитические SQL-запросы:
   - Выручка по месяцам
   - Статистика по категориям товаров
   - Общие показатели продаж
3. Визуализировать результаты с помощью matplotlib
4. Сформулировать выводы и рекомендации

## Результаты

### Выручка по месяцам

| Месяц | Выручка (руб.) |
|-------|----------------|
| 2024-01 | 191 800 |
| 2024-02 | 114 200 |
| 2024-03 | 164 000 |

### Статистика по категориям

| Категория | Выручка | Количество заказов | Средняя цена |
|-----------|---------|--------------------|--------------|
| Электроника | 470 000 | 11 | 38 300 |
| Книги | 11 000 | 14 | 800 |

### Ключевые выводы

- Основная выручка приходится на категорию **«Электроника»** (около 85%)
- Наибольшее количество заказов — в категории **«Книги»** (14 заказов), но из-за низкой цены вклад в выручку минимален
- Динамика продаж положительная: март показывает рост по сравнению с февралём

### Рекомендации

1. Расширить ассортимент электроники — основной источник дохода
2. Запустить акции в категории «Книги» для повышения среднего чека
3. Использовать книги как товар-локомотив для трафика
